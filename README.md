# Portfolio

A stunning web portfolio built with Next.js, Tailwind CSS, and Framer Motion.

## Setup

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd portfolio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env.local` file and add your Resend API key:

   ```env
   RESEND_API_KEY=your_resend_api_key
   ```

4. Run the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Animated hero section with gradient background
- Responsive navigation with Framer Motion
- Skill showcase with animated cards
- Project gallery with filters
- Contact form integrated with Resend
- Blog section with PostgreSQL backend
- Custom 404 page
